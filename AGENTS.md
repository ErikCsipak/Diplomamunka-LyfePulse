# Overview
This file is giving out a guide to AI agents working on this project.

## Frontend
UI is written using Ionic framework providing a responsive user interface.

The UI/UX is based on the screen plans under the /screenplans/patient directory.

In this project we only implement the patient-facing UI, which is the main focus of the project. The rest of the screen plans are fictive, possible developments and implementations, that will be used only for the written thesis as development proposals.

## Backend
The backend is written using Quarkus framework, which is a Java framework for building microservices and serverless applications. It provides a fast and efficient runtime environment for the backend services.
